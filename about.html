Who we are

A workshop, not an agency.

Psicoandino is a set of tools, built and used by one person — Ricardo Alberto Moreno Acevedo.

We don't sell promises: we show systems that operate, and systems still in formation, marked without decoration. What this site claims is only what the code and the git history can prove — what isn't in a commit didn't happen.

The question that moves us: how much can be reached with the least amount of resources, without losing rigor. Research for knowledge and development — not research for the title, but method someone else can audit and repeat.

Methodology

Deterministic first. The model, second, and local.

Before asking anything of a model, we ask what Python can already derive, what a check can already verify, what git already recorded. A model enters only when the work demands real cognitive generation and no rule can replace it.

The engines report, they never repair — the hand corrects, the engine observes. Every step leaves a trace: what was done, with what, and which check confirms it. Nobody opines on whether something worked; it's measured, or it stays open.

A correction never overwrites the failed attempt. Errors and reversions are kept as evidence, not cleaned out of the history. What gets built is governed by whoever uses it: visible rules, protocol, evidence — never authority by default.

Evidence over conversation

Git, refs and checks are authoritative. Chat is not a record.
